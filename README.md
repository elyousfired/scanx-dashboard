# SCANX - Token Vol/MC Dashboard

> Professional crypto token scanner inspired by stonk.fyi

## Features

- Live token data from CoinGecko API (Top 50/100/200/250)
- Market Cap + 24H Volume display
- **Vol/MC Ratio** scoring: HOT >20% / HIGH 10-20% / MID 5-10% / LOW <5%
- 7-day sparkline charts per token
- Top gainers & highest Vol/MC ratio leaderboards
- Vol/MC distribution donut chart + MCap vs Volume scatter plot
- Auto-refresh every 60 seconds
- Search, filter, and sort by any column
- Category filters: Layer 1, Layer 2, DeFi, Meme, AI, Gaming
- Dark neon theme (Bloomberg terminal meets DeFi)

## Usage

Open index.html directly in any browser. No server needed.

## Data Source

[CoinGecko Public API](https://coingecko.com) - Free tier, no API key required.
